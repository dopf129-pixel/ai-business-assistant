# Q30 — сквозные пользовательские сценарии выбора цены по прибыли с единицы

Дата: 27.10.2026
Статус: `VERIFIED`.

## Проверенные сценарии

1. Подтверждённая текущая тарифная точка через production factory и публичные Telegram handlers. Используются синтетические read-only источники; сохранённый тарифный snapshot выгружается в JSON без повторного чтения источников.
2. Ручной тариф с двумя диапазонами, переключение магазина, отказ в чтении профиля из другого магазина, повторное создание production composition и восстановление тарифа из локальной БД; JSON export выполнен через публичный handler.
3. Из неполного наблюдения бот не выводит прибыль. После повторного сбора завершённой выборки FBO postings и Returns он считает наблюдаемый процент выкупа по точному SKU, показывает выборку, доставленные и возвращённые единицы, строит явно модельную прибыль и сравнивает две цены через публичные handlers. Первая цена в потоке 100 ₽, вторая 95 ₽; возвратные расходы в прибыль/шт. не вычитаются и явно помечены.

Профиль `tests/test_unit_price_observation_collection_service.py tests/test_unit_price_observation_normalizer.py tests/test_unit_price_observation_result_service.py tests/test_unit_price_observation_quality_service.py tests/test_unit_price_profit_per_unit_end_to_end.py`: **49 passed in 2.37s** на Windows/Python 3.12. Все источники синтетические; live Ozon API и мутации через API не подключались.

## Зафиксированное правило расчёта выкупа

- Наблюдаемый процент = доставленные FBO единицы / (доставленные единицы + подтверждённые невыкупы покупателя) × 100. Размер выборки — сумма числителя и подтверждённых невыкупов.
- Для модельного знаменателя используются доставленные единицы только если полный набор отправлений прочитан, все статусы терминальные, количества сходятся, Returns полностью прочитан и нет неоднозначных отмен. `ordered_units` и число строк/отправлений сами по себе не считаются продажами.
- Возвраты показываются отдельным количеством. Их расходы не пересчитываются и не вычитаются из модельной прибыли на единицу; поздние изменения статуса могут изменить наблюдение. Результат не является официальным показателем Ozon Analytics или фактом прибыли и не доказывает причинный эффект цены.
- При неполной/неоднозначной выборке процент и модель остаются недоступными. Сравнение возможно только для результатов с одинаковым доказанным способом сбора и совместимыми допущениями.
