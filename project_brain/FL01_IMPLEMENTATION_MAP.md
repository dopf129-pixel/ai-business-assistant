## Найденные несовпадения без изменения ADR066

1. Реальный текущий поздний UI требует initialized queue, а новый case должен сохраняться до неё. Это ожидаемое расширение, не причина менять старые late-entry tables.
2. Текущий supply collector ищет только завершённые заказы/принятые акты. Нужен отдельный ограниченный наблюдатель; его отсутствие в агрегате должно сохранять прежнее наблюдение и ставить MISSING.
3. `fifo_cost_rate_changes` использует `NOT NULL` для компонентов, а полная landed cost не раскладывается владельцем. Требуется явно заданный migration/rebuild в FL03, а не фальшивое заполнение значений.
4. Изменение текущей ставки и полная replay projection сегодня не являются одним публичным пользовательским действием. Новый transition commit должен собрать все проверенные действия внутри одной repository transaction.
5. Новых решений ADR066 не требуется. Существующие tax, finance, return-recognition, planning, storage и bot lifecycle contracts сохраняются.
