# C02: действия из полноты и сохранение контекста — 25.10.2026

## Результат

Проверены существующие переходы из полноты и диагностики: себестоимость, выбор SKU, внешние расходы, локальное состояние возврата, аналитика и возврат к сохранённому расчёту. Подтверждённых дефектов в stale draft/store scope для себестоимости и произвольного периода не найдено: старые подтверждения отклоняются после смены магазина, а несовместимый SKU не переносится в новый tenant. Текущие тесты этих контрактов оставлены без ослабления.

Найдено одно воспроизводимое UX-расхождение: диагностическая кнопка `🔄 Обновить расчёт` направляла в общее меню периода. Теперь она содержит короткий `report_view_id` и запускает повторный расчёт по точным ISO-датам исходного owner/store снимка. Снимок проверяется до чтения дат; другой пользователь/магазин или истёкший callback не запускает запрос. Новый результат создаёт новый report snapshot. Повторный клик использует существующую защиту inflight-дедупликации.

Текущие кнопки внешних расходов продолжают требовать отдельного подтверждения записи и coverage; экспериментальный возврат к меню не получил кнопку повторного выбора периода. После заполнения пробела владелец может открыть исходную полноту/диагностику и обновить тот же период.

## Проверки

Связанный профиль: **105 passed, 9 deselected in 3.45s**. Девять исключённых тестов используют блокируемый локальной Windows ACL `tmp_path`: один production-factory тест и восемь storage-backed external-expense tests. Их выполнение требуется в exact-head CI; предыдущий запуск без исключения завершился именно `PermissionError: WinError 5` при создании/перечислении pytest temp root, а не прикладной ошибкой.

Новая regression `test_diagnostic_refresh_reuses_exact_period_and_owner_store_scope` подтверждает:

- диагностика создаёт `period_profit_refresh:<view-id>`;
- повторный запрос получает исходные `2026-08-01` и `2026-08-31`, `compare_previous=True`;
- успешный refresh выдаёт новую ревизию снимка;
- чужой owner и другой store отклоняются без запроса к query service.
