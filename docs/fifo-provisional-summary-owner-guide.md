# Предварительная оценка себестоимости по оборотным ведомостям

Экран «Предварительная оценка FIFO» нужен, когда фактическую историю FIFO пока нельзя достоверно восстановить. Он показывает диапазон себестоимости выкупов как сценарий и не меняет фактическую себестоимость или прибыль.

## Какие отчёты выбрать

1. Откройте карточку незавершённой партии и нажмите «Предварительная оценка FIFO».
2. Выберите полную оборотную ведомость за один день **D**. Период должен быть подтверждён владельцем; дата из имени файла сама по себе недостаточна.
3. Выберите полную оборотную ведомость движений, начинающуюся **на следующий день D+1**. Если нужных отчётов в списке нет, добавьте их через существующую загрузку и подтвердите период, затем откройте предварительную оценку снова.
4. Снимок конца D и начало ведомости D+1 должны совпасть по всем восьми категориям остатков, а контрольные суммы обоих документов должны быть нулевыми.

## Допущения и результат

Экран отдельно попросит подтвердить, что весь остаток снимка относится к старой партии и что все приходы из принятых поставок в выбранном окне относятся к новой партии. Если это неверно или неизвестно, расчёт не покажет денежный итог.

Если закрывающий остаток старой партии неизвестен, оставьте широкую границу. Можно задать одно число или диапазон только как гипотезу сценария. Частично замеченное количество в доставке не доказывает полный остаток старой партии.

Итог показывает диапазоны старых и новых выкупов и брутто-себестоимость выкупов **до сторно возвратов**. Края диапазонов связаны между собой: не складывайте два минимума или два максимума как независимые суммы. При ненулевых неподдержанных движениях, разнице в балансе, несовпадении периода/SKU/категорий или конфликте источников денежный результат блокируется.

## Границы

- Сводный результат не восстанавливает порядок событий внутри периода, не определяет день исчерпания старой партии и не доказывает фактическое распределение по отдельным продажам.
- Частичный CSV заказов и компенсационные S/AA могут отображаться отдельно, но не меняют количество выкупов из ведомости.
- Этот экран не создаёт FIFO-слои/списания, не меняет себестоимость и не пересчитывает Period Profit или Return COGS.
- Для фактической себестоимости по датам продаж требуются полные связанные данные событий; используйте соответствующие отдельные шаги фактического FIFO-мастера.
