# Назначение проекта

Ozon AI Assistant — интеллектуальный помощник продавца Ozon.

Цель проекта — автоматически получать реальные данные из Ozon Seller API, анализировать состояние товаров, остатки, риски, финансы и экономику товаров, строить прогнозы и помогать принимать решения.

## Прогноз остатков

Работает `StockForecastService`.

После накопления минимум двух ежедневных снимков рассчитываются:

- изменение остатков;
- средний расход;
- прогноз количества дней запаса;
- статус запаса.

# Экономика товара

## ProductCostService

Реализовано хранение себестоимости товара в SQLite.

Хранятся:

- Product ID
- SKU
- Offer ID
- себестоимость одной единицы
- валюта
- дата изменения

Доступны операции:

- установка себестоимости;
- обновление;
- получение;
- удаление;
- получение списка себестоимостей.

---

## ProfitService

Рассчитывает экономику отдельного товара.

Используются:

- выручка;
- чистое начисление Ozon;
- количество товарных начислений;
- себестоимость единицы.

Рассчитываются:

- себестоимость проданных товаров;
- валовая прибыль;
- прибыль на одну единицу;
- маржинальность.
