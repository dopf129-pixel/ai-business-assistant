# Назначение проекта

Ozon AI Assistant — интеллектуальный помощник продавца Ozon.

Цель проекта — автоматически получать реальные данные из Ozon Seller API, анализировать состояние товаров, остатки, риски, финансы и экономику товаров, строить прогнозы и помогать принимать решения.

---

## ProfitService

Рассчитывает экономику отдельного товара.

Используются:

- выручка;
- чистое начисление Ozon;
- количество подтверждённых продаж;
- себестоимость единицы.

Рассчитываются:

- себестоимость проданных товаров;
- валовая прибыль;
- прибыль на одну единицу;
- маржинальность.

Формула валовой прибыли:

```text
Валовая прибыль =
Чистое начисление Ozon
− Себестоимость проданных товаров
```

Для seller-facing Period Profit денежным авторитетом остаётся account-level Ozon finance. `unknown != zero`; COGS возврата разрешается только после отдельных recognition / authorization / commit / no-double-counting gates. Отчёт остаётся `read_only=True`, `executed=False`.
