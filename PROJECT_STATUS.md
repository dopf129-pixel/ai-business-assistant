# Назначение проекта

Ozon AI Assistant — интеллектуальный помощник продавца Ozon.

Цель проекта — автоматически анализировать состояние товаров, получать реальные данные из Ozon Seller API, оценивать риски, прогнозировать изменения, анализировать финансы и помогать принимать решения на основе искусственного интеллекта.

## Прогноз остатков

Работает StockForecastService.

Использует ежедневную историю.

После накопления минимум двух снимков рассчитываются:

- средний расход
- изменение остатков
- прогноз количества дней запаса
- статус запаса
